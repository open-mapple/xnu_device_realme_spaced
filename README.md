# xnu_device_realme_spaced

The realme 8i (`spaced`: MediaTek Helio G96 / MT6781, Mali-G57 MC2, UFS 2.1, 1080 x 2412) for Open Mapple:
its configuration (`device.conf`, `configs/`), its firmware list (`pull-firmware.sh`, which copies the touch
and Wi-Fi firmware off your own phone) and its tools. `lunch mapple_spaced` selects it.

Checked out at `device/realme/spaced` by the [Open Mapple manifest](https://github.com/open-mapple/manifest), which says how to get, build and install it.
